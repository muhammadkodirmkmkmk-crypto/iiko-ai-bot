# iiko Telegram Bot

ИИ-ассистент для ресторана на базе Claude + iiko API.

## Переменные окружения (Railway Variables)

| Переменная | Значение |
|---|---|
| `TELEGRAM_TOKEN` | Токен бота от @BotFather |
| `ANTHROPIC_API_KEY` | Ключ Anthropic API |
| `IIKO_SERVER` | `xan-kokand.iiko.it` |
| `IIKO_LOGIN` | `SUPERADMIN` |
| `IIKO_PASSWORD` | Пароль iiko |
| `ALLOWED_USERS` | ID пользователей через запятую |

## Что умеет бот

Просто напишите боту на русском или узбекском:

- "Какая выручка сегодня?"
- "Покажи официантов и их выручку"
- "Сколько гостей было сегодня?"
- "Какие типы оплаты сегодня?"
- "Покажи удалённые блюда"
- "Выручка за эту неделю"
